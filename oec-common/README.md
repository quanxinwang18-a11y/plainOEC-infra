# oec-common

OEC 公共能力包，提供跨项目复用的通用工具型 Skills。

## Skills

| Skill | 用途 |
|-------|------|
| `html-slides` | 基于 HTML/CSS 创建可交互的演示幻灯片 |
| `record-gif` | 录制屏幕操作生成 GIF 动图 |

Skills 按需独立触发，无依赖关系。不要求项目初始化，不创建项目级配置文件。

## 安装

```bash
claude plugin install oec-common@plainOEC-infra --scope user
```
