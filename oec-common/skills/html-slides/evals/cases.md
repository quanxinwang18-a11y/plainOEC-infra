# html-slides eval cases

## Positive cases

- “把这份季度复盘 Markdown 做成 12 页、可以浏览器演讲的 HTML 幻灯片。”
- “Create a five-slide HTML deck from this launch brief and the supplied brand assets.”
- “做一份三页的产品路演 deck，只要 HTML，不需要 PPTX。”
- A nine-slide deck with no clear visual direction first produces a cover and a representative
  content slide before batching the remaining pages.

## Negative cases

- “编辑这个现有 PPTX 并保留母版。”需要 PowerPoint 专用能力，不使用本 Skill。
- “Export this presentation as a PDF only.” is outside the promised HTML-first deliverable.
- “录制产品操作并导出 GIF。”属于录屏或视频能力。
- “Build a production landing page with a backend signup flow.” is a website/application task.
- Missing business metrics remain explicit placeholders instead of being fabricated for visual
  balance.
